Anexo A, Export de notas via API (copiar e colar no Terminal)

1. Obter o token do professor:

TOKEN=$(curl -s -X POST "https://api.harven.eximiaventures.com.br/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"ra": "hugo.capitelli", "password": "Harven@2026"}' | python3 -c "import json,sys; print(json.load(sys.stdin)['access_token'])")

2. Descobrir o ID da disciplina:

curl -s "https://api.harven.eximiaventures.com.br/disciplines" \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool | head -30

3. Export JSON (troque DISC_ID pelo id do passo anterior):

curl -s "https://api.harven.eximiaventures.com.br/disciplines/DISC_ID/grades/export" \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool

4. Export CSV (baixa a planilha na pasta atual):

curl -s "https://api.harven.eximiaventures.com.br/disciplines/DISC_ID/grades/export?format=csv" \
  -H "Authorization: Bearer $TOKEN" -o notas.csv && open notas.csv

5. Teste de escopo (passo 64): repita o passo 1 com rafael.bin e rode o passo 3 de novo. Esperado: 403.
